What's inside

Built for the entire subtitle pipeline.

From the moment you drop an MP4 to the moment you export, every step is handled on-device — fast, private, and under your control.

Soft Subtitles

Mux as a toggleable track inside the MP4. No re-encode, original quality preserved — viewers can switch on or off.

Hardcoded Subtitles

Burn into the video frame for Instagram, TikTok, and GitHub previews where soft tracks aren't supported.

Font Customization

Pick the family, size, color, outline, shadow, alignment and vertical margin. Preview a single frame before generating the whole video.

GPU Accelerated

CUDA-powered faster-whisper with CTranslate2 runs `large-v3` in float16. No GPU? It automatically falls back to CPU with int8.

Editable SRT

Fix a name, tighten a line, swap wording. Edit the generated subtitles in the UI and regenerate the video instantly.

100% Local

All inference runs on your machine. No API keys, no cloud uploads, no telemetry. Your footage stays on your disk.

How it works

Three steps. Zero cloud calls.

ffmpeg extracts audio, faster-whisper transcribes, ffmpeg muxes it back. The whole loop runs locally in seconds.

01 — INPUT

Upload

Drop one or many MP4 files into the web UI. ffmpeg extracts a 16 kHz mono WAV track from each one — no upload, no waiting.

02 — TRANSCRIBE

Generate

faster-whisper detects the language and writes a perfectly-timed `.srt`. CUDA by default, CPU fallback if no GPU is found.

03 — EXPORT

Download

Get back a `_subtitled.mp4` with a toggleable track (or burned-in for socials) plus the standalone `.srt` file for editing elsewhere.

Quick start

Up and running in one script.

`setup.sh` creates a venv, installs dependencies, and pre-downloads every Whisper model size. Then start the web UI.

Prerequisites

Two system tools and a Python environment — that's it.

  • ffmpeg — install via apt install ffmpeg or brew install ffmpeg
  • Python 3.10+ with uv recommended (or python3-venv)
  • NVIDIA GPU with CUDA recommended — CPU mode works automatically
~/video-subtitler 
$ git clone https://github.com/nick8592/video-subtitler.git
$ cd video-subtitler
$ ./setup.sh
  → creates venv, installs deps, pre-downloads Whisper models
$ python3 app.py
Opens the web UI at http://127.0.0.1:7860
